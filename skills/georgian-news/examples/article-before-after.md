# One article, before and after

## Before (weak model draft)

> **გასაოცარი სიახლე: NVIDIA-მ გამოუშვა ახალი ჩიპი.**
>
> მნიშვნელოვანია აღინიშნოს, რომ თანამედროვე სამყაროში ხელოვნური ინტელექტი თამაშობს უფრო და უფრო დიდ როლს.
> ამ კონტექსტში, ენვიდია, რომელიც არის ჩიპების წარმოების ლიდერი, გააკეთა განცხადება, რომ ახალი ჩიპი იქნება
> 2.5-ჯერ უფრო სწრაფი — და ეს არის ის, რაც მას ხდის განსაკუთრებულს. კომპანიის მიერ იქნა აღნიშნული, რომ
> 5 დიდი კომპანიები უკვე იყენებენ მას. ამიტომ, ეს ჩიპი რევოლუციას მოახდენს ინდუსტრიაში.

## After (editor)

> **NVIDIA-მ ახალი AI ჩიპი წარადგინა**
>
> NVIDIA-მ ხელოვნური ინტელექტისთვის ახალი ჩიპი წარადგინა. კომპანიის თქმით, ის წინა მოდელზე 2,5-ჯერ
> სწრაფია.
>
> NVIDIA-ს განცხადებით, ჩიპს უკვე ხუთი დიდი კომპანია იყენებს.

## What changed and why

| Change | Rule |
|---|---|
| headline: no hype, no period, actor + verb | georgian-news: headlines |
| deleted `მნიშვნელოვანია აღინიშნოს`, `თანამედროვე სამყაროში`, `ამ კონტექსტში` | AI filler |
| `ენვიდია` → `NVIDIA` | Latin brands |
| `ენვიდია ... გააკეთა განცხადება` → `NVIDIA-მ ... წარადგინა` / `NVIDIA-ს განცხადებით` | ergative; calque |
| `2.5-ჯერ` → `2,5-ჯერ` | decimal comma |
| `—` removed | no dashes |
| `ეს არის ის, რაც მას ხდის განსაკუთრებულს` deleted | calque, no fact |
| `კომპანიის მიერ იქნა აღნიშნული` → `NVIDIA-ს განცხადებით` | passive → attribution |
| `5 დიდი კომპანიები უკვე იყენებენ` → `ხუთი დიდი კომპანია იყენებს` | numeral + singular |
| `ამიტომ ... რევოლუციას მოახდენს` deleted | connector claim + hype not in source |
| `ჩიპების წარმოების ლიდერი` deleted | unsourced claim |
| added `კომპანიის თქმით` | the speed claim is the company's, not a fact |
