# Georgian Endings for Latin-Script Names and Acronyms

One deterministic, documented standard for declining foreign (Latin-script) brand names, product titles, technologies, and acronyms in published Georgian copy.

---

## 1. Classification by Final Spoken Sound

In Georgian writing, foreign names remain in the Latin alphabet (`Microsoft`, `Meta`, `OpenAI`). Case endings attach after a mandatory hyphen (`-`).

**The Golden Rule:** The grammatical class and attached ending are governed strictly by the **FINAL SOUND as a Georgian speaker pronounces the name**, NEVER by the last Latin letter on paper.

Examples of phonetic vs orthographic endings:
- `Claude`: ends in consonant /d/ (silent `e`) → consonant class (`Claude-მა`, `Claude-ს`, `Claude-ის`)
- `Apple`: ends in consonant /l/ (syllabic `le`) → consonant class (`Apple-მა`, `Apple-ს`, `Apple-ის`)
- `Google`: ends in consonant /l/ (silent `e`) → consonant class (`Google-მა`, `Google-ს`, `Google-ის`)
- `Porsche`: ends in vowel /e/ (`პორშე`) → -ე class (`Porsche-მ`, `Porsche-ს`, `Porsche-ს`, `Porsche-თი`)
- `ChatGPT`: ends in /tiː/ (letter T = `ტი`, vowel /i/) → -ი sound class (`ChatGPT-მ`, `ChatGPT-ს`, `ChatGPT-ს`, `ChatGPT-ით`)
- `OpenAI`: ends in diphthong /aɪ/ (`აი`, ending in /i/ glide) → -ი sound class (`OpenAI-მ`, `OpenAI-ს`, `OpenAI-ს`, `OpenAI-ით`)

### The 5 Phonetic Classes

1. **Consonant sound (`consonant`)**: The name ends phonetically in a consonant (e.g., `Google`, `Microsoft`, `Apple`, `Amazon`, `Intel`, `Netflix`, `Claude`, `DeepSeek`, `Anthropic`, `Linux`, `Windows`, `GitHub`).
2. **-ა sound (`a`)**: The name ends phonetically in the vowel /a/ (e.g., `Meta`, `Tesla`, `NVIDIA`, `Toyota`, `Honda`, `Kia`, `Puma`, `Zara`, `IKEA`, `Coca-Cola`, `Figma`, `Java`).
3. **-ო / -უ sound (`o-u`)**: The name ends phonetically in /o/ or /u/ (e.g., `Nintendo`, `Baidu`, `Volvo`, `Lenovo`, `Cisco`, `Subaru`, `Ubuntu`, `Go`).
4. **-ე sound (`e`)**: The name ends phonetically in /e/ (e.g., `Porsche`, `Chevrolet`, `BMW`).
5. **-ი sound (`i-sound`)**: The name ends phonetically in /i/, or a diphthong ending in /i/ (/aɪ/, /eɪ/, /ɔɪ/) (e.g., `OpenAI`, `Spotify`, `Gemini`, `Perplexity`, `Sony`, `eBay`, `Audi`, `Ferrari`, `Hyundai`, `Xiaomi`, `Midjourney`, `Runway`, `Stability AI`, `Airbnb`, `ChatGPT`).

### Initialisms vs Acronyms

- **Initialisms read as individual letters**: Follow the spoken sound of their **final letter**:
  - Final letter ends in an -ი sound (B `/ბი/`, C `/სი/`, D `/დი/`, G `/ჯი/`, P `/პი/`, T `/ტი/`, V `/ვი/`, Z `/ზედი/`, I `/აი/`, Y `/უაი/`): `AMD` (დი → `i-sound`), `TSMC` (სი → `i-sound`), `LG` (ჯი → `i-sound`), `HP` (ფი → `i-sound`), `BYD` (დი → `i-sound`), `API` (აი → `i-sound`), `CLI` (აი → `i-sound`), `UI` (აი → `i-sound`), `IT` (აი-ტი → `i-sound`), `SSD` (დი → `i-sound`), `SDK` (კეი → `i-sound`).
  - Final letter ends in a consonant (F `/ეფ/`, L `/ელ/`, M `/ემ/`, N `/ენ/`, R `/არ/`, S `/ეს/`, X `/იქს/`): `IBM` (ემი → `consonant`), `ASML` (ელი → `consonant`), `ARM` (ემი → `consonant`), `iOS` (ესი → `consonant`), `macOS` (ესი → `consonant`), `LLM` (ემი → `consonant`), `RAM` (ემი → `consonant`), `URL` (ელი → `consonant`), `SQL` (ელი → `consonant`).
  - Final letter ends in an -უ sound (U `/იუ/`): `GPU` (იუ → `o-u`), `CPU` (იუ → `o-u`).
  - Final letter ends in an -ე sound (W `/ვე/`): `BMW` (ვე → `e`).
- **Acronyms read as words**: Follow the spoken sound of the whole word:
  - `NATO` (/ნატო/ ends in /o/) → `o-u` class (`NATO-მ`, `NATO-ს`, `NATO-ს`, `NATO-თი`)
  - `NASA` (/ნასა/ ends in /a/) → `a` class (`NASA-მ`, `NASA-ს`, `NASA-ს`, `NASA-თი`)
  - `UNESCO` (/იუნესკო/ ends in /o/) → `o-u` class (`UNESCO-მ`, `UNESCO-ს`, `UNESCO-ს`, `UNESCO-თი`)
  - `OPEC` (/ოპეკი/ ends in /k/) → `consonant` class (`OPEC-მა`, `OPEC-ს`, `OPEC-ის`, `OPEC-ით`)
  - `CERN` (/ცერნი/ ends in /n/) → `consonant` class (`CERN-მა`, `CERN-ს`, `CERN-ის`, `CERN-ით`)
  - `FIFA` (/ფიფა/ ends in /a/) → `a` class (`FIFA-მ`, `FIFA-ს`, `FIFA-ს`, `FIFA-თი`)
  - `UEFA` (/უეფა/ ends in /a/) → `a` class (`UEFA-მ`, `UEFA-ს`, `UEFA-ს`, `UEFA-თი`)

## 3. The -ი Sound Resolution: Why Non-Truncating with Evidence

The declension of foreign names ending in an -ი sound (`OpenAI`, `ChatGPT`, `Spotify`, `Gemini`, `Sony`, `Audi`, `Hyundai`, `Ferrari`) was previously inconsistent in the repo, alternating between `-ის` and `-ს`. This is now resolved with a definitive, evidence-backed decision.

### 1. Morphological and Phonotactic Justification

In Georgian grammar, there are two types of nouns ending in -ი in the nominative:
1. **Truncating consonant stems (კვეცადი ფუძეები)**: Nouns like `კომპიუტერი` (`კომპიუტერ-ი`), `სტუდენტი`, `ბანკი`. The final `-ი` is merely the Georgian nominative suffix attached to a consonant stem. In all other cases, this suffix truncates: ergative `კომპიუტერ-მა`, genitive `კომპიუტერ-ის`, instrumental `კომპიუტერ-ით`.
2. **Non-truncating vowel stems (უკვეცელი ხმოვანფუძიანი სახელები)**: Foreign unassimilated borrowings ending in vowels like `ტაქსი`, `რაგბი`, `ჩაი`, `ჰობი`, `ჟიური`, `მენიუ`, `კინო`. Here, the final vowel /i/ is an inseparable part of the foreign root itself. It does NOT truncate. How does `ტაქსი` decline? Nominative `ტაქსი`, ergative `ტაქსიმ`, dative `ტაქსის`, **genitive `ტაქსის` (ტაქსი + ს)**, instrumental `ტაქსითი`.

Latin-script names ending in an -ი sound (`Sony`, `OpenAI`, `ChatGPT`, `Spotify`, `Audi`) belong unambiguously to the **non-truncating vowel stem class**:
- The /i/ or /aɪ/ sound belongs to the foreign root, not to a Georgian case marker. Truncating it is orthographically impossible in Latin script (nobody writes `*OpenA-ის` or `*Son-ის`).
- Appending `-ის` (`Sony-ის`, `Audi-ის`, `Ferrari-ის`, `OpenAI-ის`) forces an unnatural hiatus or vowel duplication (`i-is`, `ai-is`), which contradicts natural Georgian phonetics and the declension of non-truncating stems (`ტაქსის`, never `*ტაქსიის`).
- Louie already decided that `-ა` stems take `-ს` in the genitive (`Meta-ს`, `Tesla-ს`, `NVIDIA-ს`) and `-თი` in the instrumental (`Meta-თი`, `NVIDIA-თი`). The -ი sound class takes `-ს` in the genitive too, so all vowel stems (-ა, -ე, -ი, -ო, -უ) share `-მ` (ergative), `-ს` (dative) and `-ს` (genitive). The instrumental and adverbial of the -ი sound class differ: `-ით` and `-ად` (`OpenAI-ით`, `ChatGPT-ით`), like Georgian `ტაქსი → ტაქსით, ტაქსად`; `-თი` would read `ჩატჯიპიტითი` (corrected in review, 2026-11-02).
