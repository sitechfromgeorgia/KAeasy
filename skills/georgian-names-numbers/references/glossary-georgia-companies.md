# Glossary: Georgian Companies, Institutions and Local Names

Table of 180+ companies, state institutions, utilities, banks, universities and brands in Georgia.

> [!IMPORTANT]
> **Local Brand Rule**: A Georgian company's own Georgian name stays in **Georgian letters** in Georgian copy (e.g. „თიბისი ბანკი“, „საქართველოს ბანკი“, „მაგთი“, „სილქნეტი“). This is an established exception to the general rule that foreign brands stay in Latin.
> **Spoken Names (TTS)**: Spoken forms follow how Georgians actually say them (e.g. `TBC` → `თიბისი`, `IT` → `აი-თი`, `შსს` → `შინაგან საქმეთა სამინისტრო`).

`ka_lint` blocks only the spellings in the data's `wrong` lists (`ტიბისი`, `ტელასი`). The rest of the Avoid column is advice: a surname or a short form can be correct when it names something else.
