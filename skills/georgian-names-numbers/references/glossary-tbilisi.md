# Tbilisi Municipal, Urban & Address Glossary

This glossary standardizes municipal districts, micro-districts, official municipal institutions, major thoroughfares, and address formatting rules for Tbilisi in written Georgian.

### Address Writing Rules in Georgian

When publishing or communicating addresses in Georgian prose or official documents:
1. **Order of elements**:
   - City / District → Street / Avenue → Number → Building (კორპუსი) → Entrance (სადარბაზო) → Floor (სართული) → Apartment (ბინა) → Postal Code (საფოსტო ინდექსი).
   - *Example*: `თბილისი 0179, ილია ჭავჭავაძის გამზ. N32, კორპ. 2, სად. 1, სართ. 4, ბინა 15`
2. **Street type postpositioning**:
   - The street/avenue type comes AFTER the genitive case of the person or place name: `შოთა რუსთაველის გამზირი` (not `გამზირი შოთა რუსთაველი`).
3. **Number indicator**:
   - Use `N` or `№` or spelled out `ნომერი` before digits: `რუსთაველის გამზ. N15` (never use `#15`).
4. **Standard abbreviations**:
   - ქუჩა → `ქ.`
   - გამზირი → `გამზ.`
   - შესახვევი → `შეს.`
   - ჩიხი → `ჩ.`
   - გზატკეცილი → `გზატკ.`
   - კორპუსი → `კორპ.`
   - სადარბაზო → `სად.`
   - სართული → `სართ.`
   - ბინა → `ბ.`
5. **Strictly avoid Russianisms**:
   - Never write `კორპ.` without case ending or as `კორპუს` without `-ი` in nominative prose.
   - Never write `პადეზდი` (подъезд) → always `სადარბაზო`.
   - Never write `ეტაჟი` (этаж) → always `სართული`.
   - Never write `კვარტირა` (квартиრა) → always `ბინა`.
   - Never write `პროსპექტი` (проспект) → always `გამზირი`.
   - Never write `პერეულოკი` (переулок) → always `შესახვევი`.
   - Never write `ტუპიკი` (тупик) → always `ჩიხი`.
   - Never write `ტრასა` (трасса) → always `გზატკეცილი`.
